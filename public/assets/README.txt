NEXORA logo slot
================

Save the official NEXORA Innovations logo in this folder as:

    nexora-logo.png

The application probes for that exact filename on start-up. When it is present,
every on-screen credit and the report headers use the real artwork. When it is
absent, a faithful inline SVG rendition is used instead, so the application is
never broken by a missing file.

Recommended: transparent or black background PNG, at least 600 px wide.
